# 📰 The Dragon News

**The Dragon News** is an English-language newspaper web application where you can read the **latest news from all over the world**. The app provides a clean, responsive, and user-friendly interface for news readers.

---

## 🌐 Live Demo
[View Live Site](https://muhammadsamimreza.github.io/The-dragon-news/)

---

## 🛠️ Technology Used

- **Frontend:** React.js  
- **Styling:** Tailwind CSS, DaisyUI  
- **Programming Language:** JavaScript  

---

## 📖 About

This is a newspaper application built with modern web technologies. Users can view the latest news across various categories, all in one place. The interface is **simple, clean, and fully responsive**, ensuring a smooth reading experience.
